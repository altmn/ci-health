# Repository presentation

The main page should help someone understand the CI task, see a concrete example, choose a workflow, and get started. Keep operational routing policy, metric contracts, and historical validation in linked guides. All examples must be synthetic/shareable and accurately identified; illustrative pipelines do not establish measured savings.

Use shared family labels where applicable: Try it, Get started, Get help, Update or remove, Where it works, Technical details, Contribute. Keep CI Health's Audit / Preflight / Optimize chooser and pipeline example distinct. Make essential text readable without images, color, or a wide table.

Provide AI prompts alongside manual commands for setup, usage, troubleshooting, and maintenance. Name the destination above each prompt. Codex uses `$` or its skill picker; ChatGPT uses actual `@` selection for an available installation. A browser help prompt guides setup and does not imply a directory listing or local execution access.

Download counters are optional **only when the displayed count is verifiably at least 100**. None is displayed because a qualifying public metric has not been established. Before adding one, record the source, metric definition, date/window, and value; use conditional display or remove it if the displayed value falls below 100. Package downloads, repository ZIPs, and installations are different metrics.

## GitHub settings when publishing

Suggested About description: “Find CI bottlenecks, review proposed changes, and validate improvements without losing required checks.” Relevant topics include `agent-skills`, `codex`, `continuous-integration`, `github-actions`, `performance`, and `testing`. Add only topics matching actual project scope. Use the repository as the homepage until another useful public documentation destination exists.

Keep release links labeled by package purpose, with the checksum visible. A future social preview should use original/shareable examples, remain readable at small sizes, use a 1280×640 canvas, and stay below 1 MB. Repository settings and directory publication are separate from source preparation.
